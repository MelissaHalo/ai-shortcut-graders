# AI Shortcut Graders

This project contains Python scripts for grading and testing student solutions.
It includes:
- `solution.py` — the main function implementation
- `grader.py` — runs hidden and public tests
- `public_tests.py` and `hidden_tests.py` — test data

## How to Run
1. Navigate to `tasks/square_number`
2. Run `python`
3. Import and test your function:
   ```python
   from solution import square_number
   print(square_number(5))
